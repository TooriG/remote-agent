## iPhoneから接続する / Connect your iPhone

1. [BEXのダウンロードページ](https://getbex.dev/)からPC用アプリを入手し、PCで起動します。
2. PCで利用するCodexまたはClaude Codeを設定し、BEXでペアリング用の招待を表示します。
3. iPhoneのBEXで「QRコードを読み取る」を選ぶか、「接続情報を入力」からPCの招待を貼り付けます。
4. 接続先とAIサービスへの送信内容を確認し、「同意して接続」を選びます。

1. Download BEX for your computer from [getbex.dev](https://getbex.dev/) and open it.
2. Configure the Codex or Claude Code account you want to use and display a pairing invitation in BEX on the computer.
3. On your iPhone, scan the QR code or paste the invitation using the manual connection option.
4. Review the Host and the information shared with AI services, then confirm the connection.

PCのBEXは起動したままにしてください。招待は1回限りです。使用済み・期限切れの場合はPCで新しい招待を表示してください。

Keep BEX running on your computer. Invitations can be used once; create a new one on the computer if an invitation has already been used or has expired.

## 問題を報告する / Report a problem

アプリのバージョン、iPhone・PCのOS、表示されたエラー、問題が起きる操作をお知らせください。接続招待、認証キー、パスワード、非公開の会話・コードは送らないでください。

Include the app version, iPhone and computer OS versions, the error shown, and the steps that caused the problem. Do not send pairing invitations, credentials, passwords, or private conversations or code.

データの取り扱い・削除については、[プライバシーポリシー / Privacy Policy](PRIVACY.md) をご覧ください。
