WINDOWS BASELINE · 2026-10-18

軽さの数字を、検証できる形で。

Windows版BEX・Codex・Claudeの、新規プロファイルでの起動初期負荷を同じPCで測定しました。BEX・Claudeは未ログイン。Codexは既存のWindows認証を自動復元してログインしたため、認証条件を揃えた比較ではなく参考値です。各アプリ1回の予備起動後、各アプリ5回の有効な測定の中央値と最小〜最大を掲載しています。

Windows desktop baseline: isolated profiles, no project, conversation or generation. BEX and Claude are signed out. Codex auto-restored existing Windows login and is a reference, not an auth-matched comparison. One excluded warm-up, then five valid launches each, with warm OS caches.

何を測ったか

  • 専有RAM（USS）：アプリ本体と、その起動で生成した全子プロセスの非共有の常駐ページを合計。BEXはHostとコンソール補助プロセスも含みます。共有ページの二重計上を避ける指標で、共有メモリ・GPUメモリ・カーネル負荷は含みません。
  • メモリの集計：起動後20〜30秒に1秒間隔で11回、psutil 7.2.2の memory_full_info() を取得。各起動の中央値を求め、さらに有効な起動の中央値を採用しました（各5回）。
  • ウィンドウ表示：プロセス生成直前から、そのプロセスツリーが所有する320×200px以上の可視トップレベルウィンドウをOSが検出するまで。確認間隔は20ms＋プロセス列挙処理時間。スプラッシュや空のウィンドウを含む可能性があり、描画完了・ログイン完了・操作可能・最初の回答までの時間ではありません。
  • 補助指標：RSSは各プロセスのワーキングセット合計で、共有ページが重複する場合があります。プライベートコミットは専用に確保した仮想メモリで、物理RAM使用量とは異なります。いずれも有効な起動の中央値です。

メモリ指標の定義：psutil API reference。

環境と揃えた条件

2026年10月18日（日本時間）。Windows 11 Home 10.0.26200、Intel Core i7-14700KF（20コア・28スレッド）、96 GB RAM、NVIDIA GeForce RTX 4090。既定のウィンドウサイズ・描画設定を使用しました。

各アプリに新しい専用プロファイルを用意し、履歴・プロジェクトは移していません。BEXは BEX_STATE_DIR と BEX_ISOLATED_HOST=1、Codexは専用の CODEX_HOME・CODEX_ELECTRON_USER_DATA_PATH、Claudeは CLAUDE_USER_DATA_DIR・CLAUDE_CONFIG_DIR を指定しました。

BEX・Claudeのログイン案内を確認。Codexは専用CODEX_HOMEでの codex login status がログイン済みを示しました。新規プロファイルだけではWindowsの保存済み認証を隔離できませんでした。Codexの検証用会話データベースは0件です。最初の連続測定で各4回とCodexの5回目を完了した後、認証確認のため停止し、同じプロファイルでClaude・BEXの最終回を完了しました。追加の確認試行でウィンドウ消失・プロセス終了やBEXの既存検証Hostの集計漏れが生じたものは不採用です。BEXの最終有効回は検証Hostも新しく起動して集計。Codexは追加試行の大きい値へ差し替えず、当初の5回目の値を維持しています。別プロファイルで試したファイル保存方式の認証分離でも自動ログインは続き、補助プロセスへのアクセス拒否も発生したため、その試行はデータに含めていません。

予備起動後のプロファイルを再利用し、毎回その検証用プロセスツリーを終了してから再起動。測定順序をBEX→Codex→Claude、Codex→Claude→BEX、Claude→BEX→Codexと巡回しました。OSの再起動・ディスクキャッシュ消去は行っていません。普段使いのアプリと実行中タスクは残したままなので、その背景負荷は統制されていません。

アプリ既定の初期化・補助プロセスも集計対象です。アイドル到達の判定は行わず、全アプリを同じ起動後20〜30秒の時間帯で採取しました。

使用バージョン

  • BEX：Windows preview 6、revision e621339163f14082c36564ce18e561227972f1dc。公開インストーラーに含まれるdevプロファイルのビルドで測定しました。
  • Codex：Windowsパッケージ OpenAI.Codex 26.1013.4894.0（実行ファイル名 ChatGPT.exe）。
  • Claude：Windowsパッケージ Claude 2.42304.0.0。

この比較で言える範囲

このPC・このバージョンの起動初期負荷を示すものです。BEXとClaudeの未ログイン状態は比較できますが、認証条件の異なるCodexとの倍率や優劣の主張には使いません。ログイン後の同じコードベース・会話・拡張機能での比較、AIの回答速度、継続作業中の消費メモリ、モバイル版、接続の安定性は測定していません。軽さの差がRustだけに起因するという因果関係や、すべてのPCで同じ結果になることも示していません。

USS excludes shared and GPU memory. Timing ends at OS window visibility, not usable-content readiness. Codex authentication differs; do not use its figures for direct superiority or multiplier claims. Existing background workloads remained running. Results do not establish coding performance, mobile performance, network reliability, or a causal advantage from a programming language. BEX uses the dev-profile build shipped in preview 6.

全データと再現方法

全15回＋除外した予備起動3回のJSONには、各サンプルのプロセス別メモリ、集計値、実行ファイルのSHA-256を含みます。失敗した起動確認の試行は本測定に含めていません。

測定スクリプトと集計・整合性検証スクリプトを公開しています。Windows、Python 3.10以降、psutil 7.2.2が必要です。実行ファイルのパスを記した設定JSON（name・version・executable の配列）を用意し、次を実行します。

python scripts/benchmark-desktop.py --config config.json --output results --runs 5
python scripts/summarize-desktop-benchmark.py results benchmark.json

検証用プロセスだけを終了します。プロファイルにはアプリが生成した認証・ログなどが残り得るため、再現時にプロファイルそのものを公開せず、集計JSONを使用してください。
