Features

机の前にいなくても、
開発は進む。

作業はいつもあなたのコンピューターで。bexはそれを、手元のどの画面からでも続けられるようにします。

続きは、ポケットから。

Macで始めた会話を、iPhoneやAndroidでそのまま続けられます。タスクの状態はロック画面とDynamic Islandに表示され、タップすればその会話が開きます。

  • 全端末で同じ会話・同じ下書き
  • iPhoneのLive Activitiesで進み具合を確認
  • 切断しても実行は続き、つなぎ直せば最新の状態から

選んだ文章で、すぐ質問

エージェントの回答を選んで下書きに引用したり、サイドチャットで聞き返したり。元の会話はそのまま残ります。

タスクごとに、自動でワークツリー

新しいタスクは専用のGitワークツリーで動くので、作業どうしがぶつかりません。マージ済みのものは自動で片付けられます。

話しかけて指示する

音声入力で話した内容がそのまま下書きに入ります。録音に失敗しても、書きかけの文章は消えません。

承認も質問も、外出先で

コマンド実行の許可や、エージェントからの質問にスマホから答えられます。待たせている時間がなくなります。

ファイル、差分、ターミナル

変更の要約から差分を開き、Host上のファイルを編集し、ネイティブのターミナルを操作できます。

ログインしたままのブラウザ

ChromeのCookieを取り込んで、bexのブラウザでも同じサイトにログインしたまま確認できます。

How it works

3ステップで、つながる。

  1. 01

    Hostを起動する

    作業するコンピューターでbexを開くと、Host（常駐プログラム）が起動します。Codex・Claude Codeのプロセスはここで動きます。

    host-daemon --name 'My Mac'
  2. 02

    QRコードでペアリング

    iPhoneやAndroidで「PCを追加」からQRコードを読み取るだけ。招待は7日間有効で、1回につき1台だけ登録できます。

    host-daemon invite | qrencode -t ANSIUTF8
  3. 03

    どこからでも指示する

    LANでもインターネット越しでも、同じ認証済みの接続で会話できます。電車の中から、ソファから、続きをどうぞ。

    agent-cli <connection> send <thread> "テストを直して"

Security

コードは、あなたの
コンピューターに。

bexはクラウドにコードを預けません。エージェントが動くのは、あなたが信頼するコンピューターだけです。

  • エンドツーエンドで暗号化

    端末とHostはirohのQUICで直接つながります。中継を通る場合も、中継サーバーは会話を復号できません。

  • 登録した端末だけ

    招待は1回1台。不要になった端末はいつでも取り消せます。識別鍵は所有者だけが読めるファイルに保存されます。

  • 認証は各エージェントのまま

    ログイン情報はCodexとClaude Code自身が管理します。bexがトークンをコピーしたり、別のAPIを直接呼んだりはしません。

  • 広告もトラッキングもなし

    bexには広告や広告トラッキングの機能はありません。
